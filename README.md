# 🐍 Snake — Q-Learning (Q-Table)

Игра Змейка, в которой агент обучается играть самостоятельно с нуля,  
используя **табличный Q-Learning** — без нейросетей, без внешних ML-библиотек.

---

## 📸 Демо

> Запусти сам и наблюдай, как агент переходит от хаотичных движений к осознанной стратегии.

---

## 🧠 Как это работает

### Q-формула (Bellman equation)

$$Q(s, a) \leftarrow Q(s, a) + \alpha \cdot \left[ r + \gamma \cdot \max_{a'} Q(s', a') - Q(s, a) \right]$$

| Символ | Значение |
|--------|----------|
| `Q(s, a)` | ценность действия `a` в состоянии `s` |
| `α` (alpha) | скорость обучения — насколько быстро обновляется Q |
| `r` | награда за текущий шаг |
| `γ` (gamma) | дисконт — насколько важны будущие награды |
| `max Q(s', a')` | лучшее возможное значение из нового состояния |

**Простыми словами:** агент корректирует своё «мнение» о действии,  
сравнивая ожидание с тем, что получилось на самом деле.

### Q-таблица

Реализована как обычный Python-словарь `dict[tuple, np.ndarray]`:
- **Ключ** — кортеж из 8 бит, описывающих состояние
- **Значение** — массив из 3 чисел (Q-значение для каждого из 3 действий)

### Состояние (8 бит)

```
[0] опасность прямо
[1] опасность вправо (относительно курса)
[2] опасность влево  (относительно курса)
[3] текущее направление (0–3)
[4] еда выше головы
[5] еда ниже головы
[6] еда левее головы
[7] еда правее головы
```

### Действия

| Код | Действие |
|-----|----------|
| `0` | прямо |
| `1` | повернуть вправо |
| `2` | повернуть влево |

### Награды

| Ситуация | Награда |
|----------|---------|
| Съела еду | `+10` |
| Приближение к еде | `+1` |
| Удаление от еды | `−1.5` |
| Смерть (стена/тело) | `−10` |
| Превышение MAX_STEPS | `−5` |

|---------|----------|
| `↑` | увеличить скорость |
| `↓` | уменьшить скорость |

## ⚙️ Гиперпараметры

| Параметр | Значение | Описание |
|----------|----------|----------|
| `ALPHA` | `0.15` | скорость обучения |
| `GAMMA` | `0.95` | дисконт будущих наград |
| `EPS_START` | `1.0` | начальный epsilon (100% случайных действий) |
| `EPS_END` | `0.01` | минимальный epsilon |
| `EPS_DECAY` | `0.997` | множитель epsilon после каждого эпизода |
| `MAX_STEPS` | `GRID² × 3` | максимум шагов за эпизод |

## 📜 Алгоритм — шаг за шагом

```
1. Наблюдаем состояние s (8-битный кортеж)
2. Выбираем действие a:
   - с вероятностью ε → случайное (exploration)
   - иначе → argmax Q(s, a) (exploitation)
3. Выполняем действие → получаем r и s'
4. Обновляем Q-таблицу по формуле Беллмана
5. s = s', переходим к шагу 1
6. После каждого эпизода: ε = ε × EPS_DECAY
```
